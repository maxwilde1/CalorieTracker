# CalorieSense

An IoT and AI-powered calorie-tracking system that uses an ESP32-CAM to photograph meals and estimate their nutritional content through a mobile application.

## Project Overview

CalorieSense aims to simplify food tracking by allowing users to take a photograph of their meal using a physical camera rather than manually logging food.

## How it works:

ESP32-CAM — Captures a photograph of a meal.

Wi-Fi — Transfers the image to the application.

OpenAI API — Analyses the photograph to estimate calories and nutritional information.

Mobile App — Displays and stores meals, allowing users to track their daily intake.

## Technologies

Hardware: ESP32-CAM, OV2640 camera

Embedded programming: C++ / Arduino

Mobile application: React Native, Expo, TypeScript

AI: OpenAI API

Version control: Git & GitHub

## Development

Originally developed using AI-assisted coding, CalorieSense is now being rebuilt from scratch with an emphasis on understanding the underlying code, simplifying the architecture and improving maintainability.
